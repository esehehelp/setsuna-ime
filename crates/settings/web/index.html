入力方式

ローマ字・かな入力
AZIK は木村清氏考案の拡張ローマ字入力、JIS かなは JIS 配列のかな入力です。Mozc 形式（入力・出力・保留のタブ区切り）のカスタム表ファイルも指定できます。
カスタム表ファイルのパス
「ファイル」選択時に読み込むローマ字表ファイルのパスを指定します。
入力ミスの補正
ローマ字として解釈できない入力に対し、隣接キー・余分なキー・文字の入れ替えを補正した候補を提示します（例: kaisga → 会社）。「ず／づ」の取り違えも補正します（例: tuzuku → 続く）。
スペースで末尾の文節だけを変換
スペースを押すと文全体を変換し、最後の文節の候補だけを表示します。前の文節は変換したまま残ります。もう一度スペースでその文節の次の候補、← / → でほかの文節に移ります。オフのときは文全体の候補を表示します。
/コマンド・@ファイルを直接入力
行頭や空白の直後に続く /・$・@ で始まる文字列を変換せずそのままアプリへ送ります（AI エージェントの補完機能などに便利です）。カーソル前のテキストを取得できるアプリでのみ動作します。
IME のオン／オフ切替キー
カンマ区切りで指定します。Zenkaku（半角/全角）、Henkan、Muhenkan、Eisu、Kana、Space、英字、F1〜F24 などに Ctrl+ / Shift+ / Alt+ を組み合わせられます。Ctrl+Space は多くのアプリのショートカットと競合するため、必要な場合のみ追加してください。
IME をオンにするキー
IME をオンにする専用キーを指定します。ImeOn は VK_IME_ON を送信するキーボード用です（例: Henkan）。
IME をオフにするキー
IME をオフにする専用キーを指定します。ImeOff は VK_IME_OFF を送信するキーボード用です（例: Muhenkan）。

記号・句読点

変換候補の記号幅
変換候補に含まれる記号の全角・半角を設定します。「自動」ではカーソル前の文章の表記に合わせます。
記号キーの入力文字
記号キーを押したときに入力される文字を一括設定します（全角: ！（）＃、半角: ! ( ) #。どちらも 、。・「」 は維持されます）。下のメニューからキーごとに個別設定もできます。
キーごとに個別設定
句読点のスタイル
変換候補の句読点を指定した組み合わせに統一します。
中黒を「・」に統一
変換候補の ･ · ‧ ⋅ ∙ をすべて「・」に統一します。
未入力の記号を含む候補を除外
句読点や括弧など、入力していない記号が付与された候補を除外します。
記号辞書
「やじるし」→「→」、「かっこ」→「（）」のように、読みから記号を変換候補に表示します。

日付・時刻・数字・絵文字

日付・時刻の変換候補
「きょう」「いま」「1じかんご」などの読みから日付・時刻の候補を生成します。端末のローカル時刻を使用し、曜日は今日以降の直近の日付、週は月曜始まりとして計算します。
数字・計算の変換候補
数値・和暦・簡易計算・文字コードの変換候補を生成します（例: 1234 → 1,234／千二百三十四／壱阡弐百参拾四／12:34、じゅうに → 12、2025ねん → 令和7年、れいわ7ねん → 2025年、1+2= → 3、U+3042 → あ）。
絵文字・顔文字の変換候補
「にこにこ」→「😊」「＼(^o^)／」などの候補を表示します。「えもじ」「かおもじ」と入力すると一覧から選べます。

英日混在入力

小文字入力時の自動大文字化
英日混在入力モデルの使用時、小文字で入力した英単語の表記を自動調整します。「固有名詞」は辞書に基づき変換し（例: github → GitHub、iphone → iPhone）、「略語」は英単語として読めないつづり（pc → PC、sns → SNS、usb → USB）や ok・api・id などを大文字にします。word や apple など一般名詞としても使われる語はそのまま残します。
英文の文頭を大文字にする
2 語以上の英文では文頭および . ! ? の直後を大文字にし、単独の i を I に変換します。また、文中の . や , を句読点に変換せずそのまま保持します。

読み補正モデル

補正候補を先頭に表示するしきい値
読み補正モデルが「元の読みより補正後の読みのほうが確かだ」と判断する基準値です。この値を超えたら補正後の変換を先頭に、この値以下なら 2 番目に表示します。値を下げるほど誤入力が自動補正されやすくなりますが、正しい読みが意図せず書き換わる場合も増えます（目安: 4〜5）。「既定」の値は 4 です。

文字列の置換

変換候補の文字列を自動置換
登録したルールを上から順にすべての変換候補へ適用します。

アプリ別設定

アプリごとの個別設定
実行ファイル名（例: code.exe）ごとに、起動時の IME オン／オフや各機能の有効・無効を設定できます。「既定」を選ぶと全体設定に従います。なお、URL・メール・数値・パスワードなどの入力欄ではすべてのアプリで直接入力になります。

ユーザー辞書

登録単語
読みはひらがなで入力します（ローマ字入力可）。英字・記号のみの読み（例: w → (笑)）はそのまま入力して Space キーで変換できます。読み全体だけでなく一部に一致した場合も候補に表示されます。品詞に「短縮よみ」を指定すると完全一致時のみ表示され、「抑制単語」を指定すると変換候補から除外されます。
Google 日本語入力 / Mozc、Microsoft IME、ATOK、Gboard からエクスポートした辞書ファイルをインポートできます。

学習・予測

選択した候補を学習する
確定した変換候補を記憶し、次回以降の候補順位に反映します。
学習の強さ
1.0 にすると、同じ読みで以前選択した候補が先頭に表示されます。
類似する読みへの適用範囲
読み全体の文字 bigram コサイン類似度がこの値以上の場合に学習結果を適用します。1.00 で完全一致のみに適用されます。
単語単位で学習する
選び直した単語を、前後の読みが共通する別の文にも反映します（例: きしゃ「記者」→「貴社」）。
予測変換
確定した変換履歴を記憶し、読みの途中まで入力して Tab キーを押すと予測候補を表示します。
学習履歴
非表示にした候補
変換中に Ctrl+Delete で非表示にした候補の一覧です（学習によって上位に来ていた候補の場合は、学習の取り消しのみが行われます）。

書き直し

書き直しを有効にする
Space キーで変換すると、入力内容を自然な日本語に書き直した候補を先頭に表示します。有効時は入力モード表示が「直」になります。

ベース URL
OpenAI 互換 API のエンドポイント URL を指定します（例: http://127.0.0.1:8080/v1）。
API 形式
API キー
モデル
「一覧を取得」から選択するか、モデル名を直接入力してください。
推論の深さ
推論モデル使用時の思考量を設定します。低いほど応答が速くなります。
カーソル前の文脈を送信
カーソル直前の文章も送信して文脈に沿った書き直しを行います。送信されるテキスト量が増えます。
書き直しの指示
空欄の場合は既定の指示を使用します。
書き直しモードでの変換時は、読み・変換結果（および有効時はカーソル前の文章）が選択した接続先へ送信されます。
